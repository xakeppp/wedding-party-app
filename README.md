# 💍 Свадебное приложение Рустама и Лизы

Простое приложение без сборки - чистый HTML, CSS и JavaScript.

## 🚀 Деплой на Vercel

1. Залей файлы на GitHub
2. Импортируй в Vercel
3. Готово!

## 🔐 Секретные коды

- `RUSTIK` - Рустам (админ)
- `LIZOK` - Лиза (админ)
- `BESTMAN2024` - Свидетель
- `STEAM_2024` - Комната пацанов
- `BESTY` - Комната девчонок

## 💰 Коды на монеты

- `GORKO` - 500 монет
- `BOMBOM` - 300 монет
- `HONEYMOON` - 1000 монет
- `PARTY` - 250 монет
